## Qué cambia el selector de paleta

**Índigo, Océano, Violeta, Esmeralda, Rubí y Ámbar no son fuentes.** Son temas de
color para la identidad de cada producto. El selector del toolbar actualiza:

- Acciones principales.
- Focus rings.
- Elementos seleccionados.
- Fondos `subtle`.
- La primera serie de gráficas.

La tipografía permanece estable — Geist para interfaz y encabezados, con escalas
y pesos distintos— para conservar legibilidad y consistencia. Cambia **Paleta** en la barra superior
y observa el botón “Explorar componentes” de esta portada.

## Instalación

La librería se publica como paquete privado en **GitHub Packages** bajo el scope `@piensa-it`.

1. En tu repo, crea (o edita) `.npmrc` en la raíz:

   ```
   @piensa-it:registry=https://npm.pkg.github.com
   ```

2. Autenticación (una vez por máquina/CI): exporta un token de GitHub con permiso `read:packages` como `NODE_AUTH_TOKEN`, o corre `npm login --scope=@piensa-it --registry=https://npm.pkg.github.com`.

3. Instala:

   ```bash
   npm install @piensa-it/ui-library
   ```

## Uso

```tsx
// una sola vez, en el entrypoint de la app (main.tsx / _app.tsx)
import "@piensa-it/ui-library/styles.css";
```

```tsx
import { UiProvider, Button, Card, CardContent, Layout } from "@piensa-it/ui-library";

function App() {
  return (
    <UiProvider>
      <Layout brand={<span>Mi Producto</span>}>
        <Card>
          <CardContent>
            <Button>Continuar</Button>
          </CardContent>
        </Card>
      </Layout>
    </UiProvider>
  );
}
```

Importa siempre desde la raíz del paquete (`@piensa-it/ui-library`), nunca desde rutas internas.

## Theming por marca (white-labeling)

Los componentes no tienen colores hardcodeados: todo sale de variables CSS (`--primary`, `--background`, `--success`...). Cada producto sobreescribe esas variables con su propia paleta, sin tocar un solo componente — ve la página **Tokens** en el sidebar para ver la paleta completa.

La forma más rápida: aplicar una de las seis paletas incluidas en un ancestro de la app (o de una sola sección):

```tsx
<div data-ui-palette="ocean">
  <UiProvider>{children}</UiProvider>
</div>
```

Valores disponibles: `indigo`, `ocean`, `violet`, `emerald`, `ruby`, `amber`. Cambia identidad, foco, selección y énfasis — nunca el significado universal de `success`, `warning` o `destructive`.

Para una identidad 100% propia (no una de las seis), sobreescribe los tokens directamente después de importar `styles.css`:

```css
/* estilos globales de tu app */
:root {
  --primary: 158 64% 32%; /* verde MisFin, por ejemplo */
  --primary-foreground: 0 0% 100%;
}
```

Lo mismo aplica a tipografía (`data-ui-font="inter"`, o sobreescribir `--font-sans`/`--font-heading` directamente) — ver el README del repo para la lista completa de tokens sobreescribibles.
